Server location unavailable

Why the location lookup fails, and what you can do about it.

When the server location shows "Not available", one of three things is true.

1. The server's address can't be looked up

Not every Roblox server has a publicly resolvable address. Private servers in particular are never queried at all, because the addresses aren't publicly routable. There's nothing to fix — the location simply isn't knowable.

The same applies to any address in a private range. Agentstrap skips the request entirely rather than sending something pointless.

2. ipinfo.io was rate-limited

This is the most common cause. ipinfo.io's free tier limits how many lookups you can do per month, and joining games quickly burns through it.

The error Agentstrap shows says it directly: "The server location could not be queried. You may be joining games too quickly."

Things that help:

  • Turn off Show server connection notifications on the Integrations page. The overlay does its own lookup for every server you join, and it's the biggest source of requests.
  • Wait. The limit resets over time.
  • Don't join games as fast as you can.
Failed lookups are cached. Once an address fails to resolve, Agentstrap remembers that and doesn't keep retrying it. So a server that failed won't suddenly start working later in the session.

3. ipinfo.io only knew the region

ipinfo.io sometimes doesn't have a city for an address — only a country or region. Agentstrap would rather show nothing than claim "Illinois, Illinois", so it shows "Not available" instead.

This one is outside your control.

Nothing is wrong

It's worth checking that the lookup is actually enabled. Settings → Integrations → Query server location. It also requires activity tracking to be on.

The overlay has its own lookup. If the tray notification says "Not available" but the overlay shows a city, that's expected — the overlay resolves locations independently.

Where to look next

Agentstrap's log records the exact request and the response it got back, including the error message from ipinfo.io. Open the log folder from the Command Center or the Advanced page and look for the ipinfo entries around the time you joined the server.
