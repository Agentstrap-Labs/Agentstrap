Uninstalling Agentstrap

Remove it cleanly, including the parts outside the install folder.

The fastest first step

Run diagnostics. Settings → Diagnostics → Run diagnostics. It checks eight things at once and tells you which one is wrong. Press Copy report and paste it into a bug report if you need help.

Before you file a bug

  1. Run Diagnostics and copy the report.
  2. Open the log folder from the same page and attach the most recent log file.
  3. Check the Updates page for pending configuration migrations and apply them.
  4. Confirm you're on the latest release — the Releases button opens the download page.
Logs contain server addresses. Agentstrap's logs record every HTTP request, including the ipinfo.io URLs with the game server's IP address in them. Read a log before you attach it to a public issue.
