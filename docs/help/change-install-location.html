Agentstrap Docs

Change the install location

Move Agentstrap to a different drive or folder.

Moving the install

Agentstrap's install location is set when you first run the installer, and it can be changed afterwards.

  1. Close Agentstrap completely. Check the system tray — right-click the Agentstrap icon and choose Exit. If a Roblox process is running, close it too.
  2. Move the folder. Cut %LOCALAPPDATA%\Agentstrap and paste it to its new home, for example D:\Apps\Agentstrap.
  3. Run Agentstrap from the new location. The first launch from the new path updates the shortcuts, the registry entries and the file paths Agentstrap stores.
Copy, don't move, the first time. Run Agentstrap from the new location and confirm everything works before you delete the old folder. If something's broken, you still have a working install.

What has to be updated

Moving the folder breaks a few absolute paths. Agentstrap repairs most of them on first launch, but these need checking:

WhatHow to fix it
Start Menu and desktop shortcuts Settings → Shortcuts. Toggle each one off and on again to rewrite them.
The roblox:// protocol handler Command Center → Repair Roblox links.
The uninstall entry in Windows Re-run the installer from the new location, or remove the old entry from Settings → Apps.
Custom mods and Fast Flags They live in Modifications inside the folder, so they move with it.

A cleaner option

If you'd rather start fresh than move files around, delete %LOCALAPPDATA%\Agentstrap entirely and run the installer again. The installer asks where you want it to go. You lose your settings and mods, but everything ends up consistent.

See Uninstalling Agentstrap for the full removal procedure.
