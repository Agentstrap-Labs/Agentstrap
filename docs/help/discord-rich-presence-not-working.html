Discord Rich Presence not working

Your game isn't showing up on your Discord profile.

Work through these in order — the first two cause most of the failures.

1. Is the Discord desktop app running?

Rich Presence needs the Discord desktop app, not the mobile app, not the browser version, and not the game console. If Discord isn't running when you launch Roblox, nothing appears.

If Discord is running but was started after Roblox, it usually still works — but restarting Discord is a quick thing to try.

2. Is activity tracking enabled?

Discord Rich Presence is built on top of activity tracking. If that's off, the presence never updates.

Settings → Integrations → Enable activity tracking.

Watch out for this one. Turning activity tracking off also switches off Discord Rich Presence. Turning it back on does not switch Rich Presence back on — you have to re-enable Show game activity by hand.

3. Is "Show game activity" on?

It's a separate switch, on by default, but it gets turned off along with everything else when activity tracking is disabled.

4. Check Discord's own settings

  • Open Discord → User Settings → Activities → Roblox. Make sure the toggle is on and the visibility isn't set to Nobody.
  • Some Discord privacy settings block Rich Presence entirely. Try setting your status to Online rather than Invisible.
  • Try running Discord as administrator. On some systems, a non-elevated Discord can't see an elevated Roblox process.

5. Is the presence stale?

Roblox's own Rich Presence integration can conflict with Agentstrap's. If you have Roblox's built-in Discord connection enabled in Roblox's settings, turn it off — otherwise both try to publish the same presence and Discord picks one arbitrarily.

6. The join button is missing

Join buttons come from Allow activity joining on the Integrations page, and they're only offered for public servers. Private and reserved servers can't be joined through a deeplink, so the button is hidden.

Nothing worked

Discord's own logs are in %APPDATA%\discord\logs. They say whether a connection was attempted and what Discord thought of it. Agentstrap's own log says whether it tried to publish at all — if there's no corresponding entry, the problem is upstream in activity tracking.
