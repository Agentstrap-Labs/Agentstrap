Uninstalling Agentstrap

Remove it cleanly, including the parts that live outside the install folder.

Uninstall

  1. Exit Agentstrap. Right-click the tray icon and choose Exit. Close any running Roblox processes too.
  2. Remove it from Windows. Go to Settings → Apps → Installed apps, find Agentstrap, and uninstall it.
  3. Delete the leftovers. The uninstaller doesn't remove everything. Delete %LOCALAPPDATA%\Agentstrap if it's still there.

What's left behind

Some things live outside the install folder, and the uninstaller won't touch them.

Path or keyWhat it is
%LOCALAPPDATA%\AgentstrapThe whole install: settings, mods, logs, Roblox installs.
%TEMP%\AgentstrapTemporary downloads and in-progress updates.
%LOCALAPPDATA%\RobloxRoblox's own data folder. Safe to delete — Roblox recreates it.
HKCU\Software\Classes\robloxThe protocol handler that makes Roblox links open Agentstrap.
HKCU\Software\Classes\roblox-playerThe same, for the player-specific scheme.
HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\AgentstrapThe uninstall entry, if it's still there.
HKCU\SOFTWARE\ROBLOX Corporation\Environments\RobloxPlayer\Channel\www.roblox.comThe deployment channel value.
Start Menu and desktop shortcutsPoint at the old executable path.
Registry cleanup in one command. Run PowerShell as administrator and paste: Remove-Item -Path "HKCU:SoftwareClasses oblox", "HKCU:SoftwareClasses oblox-player" -Recurse -ErrorAction SilentlyContinue

Getting back to plain Roblox

After removing Agentstrap, the roblox:// links stop working until Roblox's own installer registers them again. Run Roblox's official installer once, and it will restore the standard handler.

Roblox itself is not removed by uninstalling Agentstrap — the client files live in %LOCALAPPDATA%\Agentstrap\Versions, so deleting that folder does remove them. Roblox will be reinstalled the next time you launch it through the official installer.

Keep the folder if you're not sure. Renaming %LOCALAPPDATA%\Agentstrap to Agentstrap.backup is reversible. Delete it for good once you're satisfied.
