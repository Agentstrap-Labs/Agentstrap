Agentstrap is a fork of Bloxstrap. The original project lives at github.com/bloxstraplabs/bloxstrap, and a large part of Agentstrap's existing behaviour comes from there. Credit where it's due.

Reporting a problem

Before you open an issue, run Diagnostics and paste the report into the issue. It saves a round trip and usually answers the question on its own.

If the problem is a crash or a launch failure, attach the relevant file from Agentstrap's log folder as well. The Command Center and the Advanced page both have an Open logs button.

Logs contain IP addresses. Agentstrap's logs record every HTTP request, including ipinfo.io lookups that contain the game server's IP address. Read the log before attaching it to a public issue.

Contributing

Pull requests are welcome. The project is a WPF application on .NET 10, with the WPF UI library vendored as a submodule. Clone the repository, initialise the submodule, and build it with the .NET SDK:

git clone --recurse-submodules https://github.com/agentxco2-dev/Agentstrap
dotnet build Agentstrap/Agentstrap.csproj -c Release

If you cloned without --recurse-submodules, run git submodule update --init inside the repository first — the build fails without it.
