Agentstrap Docs

Translations

Agentstrap's interface is available in dozens of languages, and you can help translate it.

Supported languages

The interface is translated into more than thirty languages, including:

Arabic, Basque, Bulgarian, Catalan, Chinese (Simplified and Traditional), Croatian, Czech, Danish, Dutch, English, Estonian, Filipino, Finnish, French, German, Greek, Hebrew, Hindi, Hungarian, Indonesian, Italian, Japanese, Korean, Latvian, Lithuanian, Norwegian, Persian, Polish, Portuguese (Brazil), Romanian, Russian, Serbian, Slovak, Spanish, Swedish, Thai, Turkish, Ukrainian, Vietnamese.

You can change the language from the Appearance settings page, or from the language selector in the launch menu.

How it works

Translations live in resource files (Strings.resx and one per language), and the locale is applied when the interface loads. The region format is also switched to match, so dates and numbers appear the way your language expects.

Fallback behaviour. If a string is missing in your language, Agentstrap falls back to English for that string rather than showing nothing.

Translating

Translation files are plain XML, so any text editor works. The workflow is:

  1. Find the language you want to contribute to in the Resources folder.
  2. Duplicate a Strings.resx file as Strings.<code>.resx if it doesn't exist yet.
  3. Translate the values. Leave the resource names alone — they're the keys the code looks up.
  4. Save and rebuild.

Two things to be careful about:

  • Don't rename or remove keys. A missing key falls back to English, but a renamed one is a silent break.
  • Watch the formatting placeholders. Strings like {0} and {1} are substituted at runtime. They must survive translation, in the same order.
There's a script for finding unused strings. Scripts\Translations\find-unused.py reports resource keys that nothing in the code references any more, which is a good first thing to clean up when starting a new language.
