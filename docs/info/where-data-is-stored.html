Agentstrap Docs

Where data is stored

Every folder and file Agentstrap writes, what's in it, and what's safe to delete.

Agentstrap installs itself into %LOCALAPPDATA%\Agentstrap by default, and you can choose a different folder when you run the installer. Most of what it writes lives inside that install folder, but two things deliberately sit elsewhere.

The default layout

%LOCALAPPDATA%\Agentstrap\
  Agentstrap.exe           the launcher
  Settings.json            your settings
  State.json               launcher state
  Logs\                    log files (up to 15)
  Downloads\              downloaded Roblox packages
  Versions\                extracted Roblox installs
    <version-guid>\
      RobloxPlayerBeta.exe
  Modifications\           your mods, Fast Flags and custom assets
    ClientSettings\
      ClientAppSettings.json
    content\
    PlatformContent\
    ExtraContent\
  CustomThemes\            your custom themes
  Integrations\            custom integration definitions
Two folders are always here. Modifications and CustomThemes live under %LOCALAPPDATA%\Agentstrap regardless of where you install the app, so your mods survive moving the install. Everything else — settings, logs, downloads and the Roblox installs — follows the install folder.

What each thing is

PathContainsSafe to delete?
Settings.json Every preference you've set. Yes, but Agentstrap will reset to defaults on next launch.
State.json Launch history, the forced-reinstall flag. Yes, same caveat.
Logs\ Rotated log files. Contains every HTTP request Agentstrap made. Yes. The Advanced page has a Clear logs button.
Downloads\ Cached Roblox package archives. Yes, they're re-downloaded when needed.
Versions\ The extracted Roblox installs. The player executable lives here. Not recommended — Roblox will be reinstalled from scratch.
Modifications\ Your mods, Fast Flags, custom font and skybox. Yes, but you'll lose all your mods.
CustomThemes\ Custom themes you've written. Yes.

Elsewhere on disk

PathWhat
%TEMP%\AgentstrapTemporary downloads, in-progress updates and temporary logs.
%LOCALAPPDATA%\RobloxRoblox's own data, written by the game client.
%LOCALAPPDATA%\Roblox\logsRoblox's own logs. The Open Roblox logs button on the Deployment page opens this.
HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\AgentstrapThe uninstall entry, used by Settings → Apps.
HKCU\Software\Classes\robloxThe protocol handler that makes Roblox links open Agentstrap.

Changing the install location

The install location can be moved. The installer asks where you want it, and there's a walkthrough for changing it later.
