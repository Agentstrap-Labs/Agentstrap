Agentstrap Docs

Privacy policy

What Agentstrap sends over the network, what it stores on your machine, and what you can turn off.

What leaves your machine

WhenWhere it goesWhat is sent
Installing or updating Roblox Roblox's download servers Ordinary HTTP requests to fetch the client package.
Checking for Agentstrap updates api.github.com An ordinary release API request. No personal data.
Looking up a server's location ipinfo.io The game server's IP address, and the path it's looked up under. ipinfo.io necessarily sees your own IP as the connecting client, exactly as with any web request.
Showing the server connection overlay ipinfo.io The same as above, whenever the overlay is enabled.
Resolving the experience name games.roblox.com The game's universe ID.
Fetching game icons thumbnails.roblox.com The game's universe ID.
Showing your Roblox account on Discord users.roblox.com, thumbnails.roblox.com Your Roblox user ID and avatar, but only if you turn on Show Roblox account in Discord Rich Presence. Off by default.
Checking for mod updates Each mod's own releaseApiUrl Whatever URL the mod author specified. Agentstrap doesn't send anything of yours.
Agentstrap has no server of its own. There's no analytics backend, no account system, and no telemetry endpoint. Agentstrap is entirely local.

Analytics

The interface has an Analytics toggle in the Agentstrap settings section. It is on by default, but with the current build it has no endpoint to report to, so nothing is sent either way. The setting is there so the behaviour is explicit and visible rather than implied.

What stays on your machine

WhatWhereNotes
Your settings %LOCALAPPDATA%\Agentstrap\Settings.json Every toggle you've changed. Plain text and easy to inspect.
Launcher state %LOCALAPPDATA%\Agentstrap\State.json Launch status, the forced-reinstall flag and similar.
Modifications %LOCALAPPDATA%\Agentstrap\Modifications Your mods, your Fast Flags, your custom font and skybox.
Logs %LOCALAPPDATA%\Agentstrap\Logs Up to 15 rotated log files. They record every HTTP request Agentstrap makes, including the full ipinfo.io URL with the queried game server IP in it. If you share logs, those addresses go with them.
Game history Nowhere Session only, in memory, never written to disk.
Location lookups Nowhere Cached in memory for the session only. Failed lookups are cached too, so they're not retried.

See Where data is stored for the full map.

Turning things off

To stopTurn off
ipinfo.io lookups for the tray notification and dialogQuery server location on the Integrations page
ipinfo.io lookups from the overlayShow server connection notifications on the Integrations page
All server watchingEnable activity tracking on the Integrations page
Your Roblox account appearing on DiscordShow Roblox account on the Integrations page
GitHub release checksCheck for updates on the Quality of Life page
Mod update checksRemove the releaseApiUrl from the mod's manifest entry
The overlay has its own lookup. Turning off Query server location does not stop the overlay from contacting ipinfo.io. The overlay performs its own lookup whenever it's enabled. If that matters to you, switch the overlay off as well.

Roblox's own data

Agentstrap doesn't control what Roblox itself collects. The Roblox client, running under Agentstrap, talks to Roblox's services exactly as it would if you'd launched it normally, and Roblox's own privacy policy applies to that.
