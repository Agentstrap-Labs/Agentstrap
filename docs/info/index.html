The short version

QuestionAnswer
Does Agentstrap report my activity to Roblox? No. Nothing about what you're playing is sent to Roblox or to Bloxstrap. The only Roblox API calls are read-only lookups of public metadata.
Does it send anything to a Bloxstrap server? No. Agentstrap has no analytics backend of its own.
What leaves my machine? Roblox downloads, the GitHub release check, ipinfo.io lookups when you enable server location or the overlay, and per-mod update checks.
Is it malware? No. The source is public and the only official download is the GitHub release.
Can I get banned for using it? No. It doesn't interact with the client in the way exploits do. See the details.
Looking for a fix instead? The Help section covers the problems people actually run into, step by step.
