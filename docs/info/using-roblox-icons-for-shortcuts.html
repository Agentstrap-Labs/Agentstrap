Using Roblox icons for shortcuts

Extract Agentstrap's collection of Roblox icons and use them for your own shortcuts.

Agentstrap ships a set of Roblox icons covering most of the eras of the platform's logo. You can extract them to a folder and use them anywhere you like — for your own desktop shortcuts, for a launcher, or for anything else that accepts an .ico file.

Where it lives. Settings → Shortcuts → Extract Roblox icons to folder.

Extracting the icons

  1. Turn on Extract Roblox icons to folder.
  2. Press Save.
  3. Open the folder. It's called Icons, and it sits inside your Agentstrap install folder.

Because the folder lives inside the install folder, it follows Agentstrap if you move the app. If you installed somewhere else, the path is the one you chose during installation, plus \Icons.

Using them

For an Agentstrap shortcut

The simplest way is to point Agentstrap at one of them:

  1. Go to Settings → Appearance.
  2. Open the Customisation expander.
  3. Set Custom icon to one of the extracted files, using Browse.
  4. Press Save.

The same page also has an Icon dropdown, which switches the icon Agentstrap uses for its own window and taskbar button. That dropdown already includes every one of the Roblox icons, so you don't need to extract anything just to change it.

For a shortcut you created yourself

Any Windows shortcut can use them:

  1. Right-click the shortcut → Properties.
  2. Go to the Shortcut tab.
  3. Click Change Icon, then Browse to the extracted folder and pick the .ico you want.

For anything else

They're ordinary .ico files. Use them anywhere that accepts one.

Turning it back off deletes the folder. Switching the toggle off and saving removes the whole Icons folder and its contents. Copy anything you want to keep somewhere else first.
