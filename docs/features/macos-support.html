Agentstrap Docs

macOS support

Platform-aware architecture and honest capability reporting for macOS.

Agentstrap keeps its Windows application intact and introduces abstractions for platform detection, capabilities, paths, configuration storage, process launching, filesystem, logging, diagnostics, updates and backups.

Capability status

Every feature is classified as Supported, Experimental, Unsupported or Temporarily unavailable. The UI reflects the actual capability of the current platform instead of scattering ad-hoc OS checks.

Roblox on macOS

Roblox has a native macOS client. Agentstrap detects it where possible and reports unsupported configurations clearly. Windows-specific Fast Flags, registry settings, launch arguments, mods and integrations are not assumed to work on macOS. Agentstrap never bypasses anti-cheat, authentication or client integrity checks.

Limitation. macOS compilation and runtime verification require a Mac and the appropriate SDK, which may not be available in the current build environment.
