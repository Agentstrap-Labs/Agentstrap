Agentstrap Docs

Automatic backups

Automatic, integrity-checked snapshots of your Agentstrap configuration.

Agentstrap can snapshot your configuration before risky operations and on a configurable schedule.

Triggers

  • Before profile activation.
  • Before importing configuration.
  • Before significant configuration changes.
  • Before supported mod operations.
  • Before application updates.
  • On a configurable schedule.

Restore process

  1. Validate format and integrity.
  2. Show what will be restored.
  3. Create a safety backup of the current configuration.
  4. Apply restoration safely.
  5. Validate restored configuration.
  6. Report success or failure.

Backups are stored in a user-accessible location and never include authentication cookies, passwords or tokens.
