Diagnostics

Eight health checks that find broken installs, bad permissions, conflicting mods and pending migrations.

Diagnostics runs every Agentstrap health check in a single pass and groups the results by what they cover. It's the fastest way to work out why something isn't working, and the easiest way to give someone enough information to help you.

Where it lives. Settings → Diagnostics, or the Run diagnostics button on the Command Center.

Running a check

Press Run diagnostics. The checks run concurrently and a spinner appears while they work. The page doesn't run them automatically when you open it — you always trigger it yourself, so it never surprises you with network traffic.

When it finishes you get an overall verdict — Healthy, Warnings found or Problems found — plus a counter for each severity.

The eight checks

CheckCategoryWhat it looks at
Roblox installationRoblox Whether the Roblox Player executable exists in the current version folder. A missing install is a warning, not a problem — it gets installed the next time you launch.
Roblox version stateRoblox Whether Agentstrap knows which version of Roblox is installed. If the version state can't be read, it reports it as a warning.
Agentstrap configurationConfiguration Whether Settings.json loaded correctly. Failing to load is a problem, because Agentstrap falls back to defaults. It also flags non-default settings such as disabled update checking, disabled analytics, a changed web environment or enabled developer mode.
Missing filesFilesystem The files and folders Agentstrap expects: Settings.json, State.json, the Logs, Versions and Modifications folders. Missing folders that get recreated on demand are a warning; missing core files are a problem.
Invalid settingsConfiguration Individually invalid values: a process priority Windows won't accept, an unsupported locale, a custom theme file that no longer exists, a custom icon path that's gone, a matchmaker that's enabled with no place ID, or a negative minimum slot count.
Mod conflictsMods A recorded custom skybox with no images in the sky folder, an empty custom font file, and mod changes that have been set but not yet applied to Roblox.
PermissionsFilesystem Whether Agentstrap can write to its install folder, to %LOCALAPPDATA%\Roblox, and to its temp directory. It does this by creating and deleting a small probe file in each.
Update stateUpdates Whether there are pending configuration migrations, whether update checking is enabled, and whether a newer Agentstrap release exists. This is the only check that makes a network request.

Copying the report

Copy report puts a plain-text report on your clipboard, one line per check, with the details underneath where there are any. Paste it straight into a bug report.

There's also Open logs, which opens Agentstrap's log folder so you can attach the actual log files if the report isn't enough.

No file export. The report goes to the clipboard, not to a file. Paste it into a text editor if you want to keep it.
Diagnostics doesn't change your configuration. It's a read-only tool. If a check points at a fix — like pending migrations, which it tells you to apply from the Updates tab — it says so rather than doing it for you.
