Game history

A session-only list of every game you've been in, with one-click rejoining.

Need to go back to a server you just left? Game history keeps a record of the servers you've joined during the current Roblox session and lets you rejoin them directly.

Where it lives. Right-click the Agentstrap tray icon → Game history. The menu item is only present when activity tracking is enabled and Don't exit to desktop app is off.

What the list shows

Each entry has a game icon, the game name, and a line describing it:

Brookhaven RP
Builderman • 14:32 - 15:04

For non-public servers, the server type is appended:

Brookhaven RP
Builderman • 14:32 - 15:04 • Private server

Each entry also has a green Rejoin button that relaunches Roblox and joins that exact server.

Session-only, on purpose

Nothing is written to disk. Game history exists only in memory for the current Roblox session. Close Roblox and it's gone. If you're switching between games by closing Roblox each time, it won't help you.

Entries appear as you leave a game or teleport within one. Teleports inside the same experience are folded into the original entry rather than filling the list with near-duplicates, so a game that teleports you around a dozen times still shows as one row with an accurate end time.

Not every server is rejoinable. Reserved servers and some private servers can't be rejoined by deep link. The Rejoin button simply doesn't do anything for those.
