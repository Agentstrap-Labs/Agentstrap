Agentstrap Docs

Modding

Customise Roblox's own assets — cursors, sounds, fonts, the avatar background and the skybox.

Roblox stores some of its assets locally, and Agentstrap can replace them. Because the replacements live outside the Roblox install, they survive every Roblox update.

Where it lives. Settings → Mods.

How modding works

Your Modifications folder is an overlay on top of the Roblox client folder. Every time Roblox launches, the contents of Modifications are copied into the client install, replacing files with the same path.

Agentstrap\
  Modifications\
    content\
      sounds\
        ouch.ogg        <-- your version
  Versions\<version-guid>\
    content\
      sounds\
        ouch.ogg        <-- Roblox's original, kept intact
Use the Mods folder button. The Mods page has an Open mods folder shortcut that takes you straight to the right place, so you don't have to hunt for it.

Presets

These are the ready-made modifications Agentstrap provides.

PresetWhat it changes
Mouse cursor The in-game cursor. You can pick between the Default cursor and the ones from Roblox's 2013 and 2006 eras.
Old character sounds Restores the older walking, jumping and getting-up sounds.
Old avatar editor background Restores the original mobile avatar editor background image.
Emoji font Replaces the in-game emoji font. Options are Default, Catmoji, Windows 11, Windows 10 and Windows 8. The fonts are downloaded from GitHub the first time you pick one, so this option needs an internet connection. Pick Default to remove the replacement entirely.
Presets apply on the next launch. Changing one queues the change; it's copied into the Roblox install the next time Roblox starts.

Roblox Apple Emoji Mode

Roblox Apple Emoji Mode is a separate settings page. It attempts to make supported Roblox text elements render emojis in Apple's iPhone emoji style by replacing Roblox's emoji font through the same Modifications overlay used by the emoji font preset. It never changes Windows system fonts.

Where it lives. Settings → Roblox Apple Emoji Mode.

Because Apple's original emoji designs are proprietary, Agentstrap does not ship or download an Apple emoji font. You must select a compatible, legally usable Apple style colour emoji font yourself. Agentstrap validates the selected file, copies it to content\fonts\TwemojiMozilla.ttf, and keeps a backup so the previous font can be restored.

Agentstrap cannot observe Roblox's renderer, so the page reports Rendering unverified after a successful application. It never reports a verified Apple rendering result.

Supported text elements are unverified. Roblox may use different text rendering paths in different parts of the client. A font replacement can only affect the paths that actually load TwemojiMozilla.ttf.

Custom font

You can replace the game's own font with any font file on your machine. Use Choose to pick a .ttf file, and Remove to go back to the default. The file is copied to Modifications\content\fonts\CustomFont.ttf.

Game skybox

The skybox is the panorama you see in games that use one. Agentstrap can replace it with an image of your choosing.

  • Pick a .png, .jpg, .bmp, .gif or .tiff.
  • The image is squared up and written into the Roblox install on the next launch.
  • The Mods page shows a live preview of the current skybox, and lets you remove it again.

Agentstrap converts a single image into the six faces Roblox expects (sky512_up, sky512_down, and the four sides).

Use a square image. A square source gives the best result, since it's projected across a panorama.

Making your own mods

Anything not covered by a preset can be done by hand. Drop the file into the Modifications folder at the same relative path Roblox uses.

WhatPath inside Modifications
Mouse cursorscontent\textures\KeyboardMouse\Cursors\
Character soundscontent\sounds\
Fontscontent\fonts\
Emoji fontcontent\fonts\TwemojiMozilla.ttf
Avatar editor backgroundExtraContent\places\Mobile.rbxl
Surface texturesPlatformContent\pc\textures\
SkyboxPlatformContent\pc\textures\sky\
Fast FlagsClientSettings\ClientAppSettings.json
You can't replace individual icons. Roblox stores them in sprite sheets whose layout changes frequently, so replacing one reliably isn't practical.

Distributing a mod

Zip up the contents of the Modifications folder, keeping the folder structure intact, so the files sit at the root of the archive. A user then extracts it straight into their own Modifications folder.

Mods are purely cosmetic and local. They never touch the game server, and nobody else can see them.
