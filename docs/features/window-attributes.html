Custom window attributes

Force a fixed size, screen position and window title on the Roblox window every time it opens.

By default the Roblox window uses whatever size and position it last had. With custom window attributes enabled, Agentstrap applies a fixed size, position and title to the window as soon as it appears.

Where it lives. Settings → Quality of Life → Custom window attributes.

Options

OptionDefaultDetail
Enable custom window attributes Off Applies the values below to the Roblox player window once it opens. You can fill the fields in ahead of time even while this is off.
Window size Empty Width and height in pixels, as width × height. Leave a box empty to keep Roblox's own value.
Window position Empty The top-left corner in screen pixels, as x, y. Negative values are allowed, which is how you place the window on a monitor to the left of or above the primary one.
Window title Empty Replaces the title on the game window. Leave it empty to keep Roblox's own title.

Resetting

Reset window attributes clears the size, position and title back to empty. It doesn't turn the master switch off, and it doesn't save — you still need to press Save.

How it works

The values are applied by Agentstrap's background watcher process, not by the settings window. After the Roblox process starts, the watcher:

  1. Waits for the Roblox window handle to appear (up to 60 seconds).
  2. Waits another 1.5 seconds for Roblox to finish sizing itself.
  3. Applies the size, position and title with the Windows API.
A watcher process stays running while Roblox does. That's how the attributes get applied to a window that didn't exist when you pressed Save.
Invalid values are dropped silently. A size of zero or less, or anything that isn't a number, is discarded and treated as "leave it to Roblox". The same goes for a title that's only whitespace.
Multi-monitor tip. Negative X and Y values are the easiest way to place the window on a secondary display. If your secondary monitor is to the left of the primary one, try -1920 for the X position.
