Profiles

Save, switch, compare and restore whole configuration profiles.

Profiles capture a complete Agentstrap configuration so you can switch between setups (for example a performance profile and a visual profile) without losing either.

What a profile stores

  • Settings (launch, window, theme, integrations, mod selections where supported).
  • Fast Flag configuration.
  • Mod selections where the platform supports them.

Operations

  • Create from current configuration.
  • Create from a default template.
  • Duplicate, rename, activate, export, import.
  • Compare two profiles or current settings to a profile.
  • Restore previous settings from a backup.
Safety. Profile activation creates a backup of the current configuration first. Imported profile data is validated; arbitrary imported content is never executed.
