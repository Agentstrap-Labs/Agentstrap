Where each setting lives

Agentstrap's settings window has a sidebar with thirteen pages. This is the map you need to find any option:

Settings pageWhat you'll configure there
Command CenterLaunch buttons, live status, repair shortcuts
IntegrationsActivity tracking, server location, overlay, Discord, custom integrations
BootstrapperLaunch confirmation, background updates, forced reinstall
ModsCursors, sounds, emoji font, custom font, skybox
Engine SettingsFast Flag presets, preset bundles, validator, flag editor
Quality of LifeUpdate checking, background updates, custom window attributes
AppearanceTheme, accent colour, custom themes, software rendering
ShortcutsStart Menu and desktop shortcuts, Roblox icons
UpdatesAgentstrap releases, mod updates, config migrations, NEXUS status
DiagnosticsHealth checks and the report
DeploymentChannel pinning, launch behaviour, matchmaker
AdvancedNEXUS mode, developer tools, maintenance
AgentstrapUpdate checking, analytics, web environment, export data
Save button. Every page writes into an in-memory copy of your configuration. Nothing touches disk until you press Save in the bottom-right of the settings window. Three things save immediately: changing the process priority, resetting NEXUS to defaults, and restarting Agentstrap.
