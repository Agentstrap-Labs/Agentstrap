Discord Rich Presence

Show the game you're playing on your Discord profile, and let friends join it from there.

Agentstrap publishes your current Roblox game to Discord, so anyone looking at your profile can see what you're playing and jump into it.

Where it lives. Settings → Integrations → Discord Rich Presence.

Requirements

  • Activity tracking must be enabled. See Activity tracking.
  • The Discord desktop app must be installed and running. The mobile app doesn't work.

Options

OptionDefaultWhat it does
Show game activity On Publishes the Roblox game you're playing to your Discord profile. Turning this off also turns off the two options below.
Allow activity joining On Shows the join buttons on your Discord profile so friends can enter the game you're in.
Show Roblox account Off Also shows which Roblox account you're playing with, along with its avatar. This fetches your Roblox user ID and profile picture from Roblox's public API.

Extra details on your profile

Depending on what you're playing, your Discord presence can show more than just the game name:

  • The number of players currently in the server.
  • The server's location, when server location querying is enabled.
  • Join buttons, when activity joining is on.

The "Copy invite deeplink" item in the Agentstrap tray menu gives you a link to the server you're in, but only while you're in a public server.

If it isn't working

See Discord Rich Presence not working for a step-by-step fix.
