Server connection push notifications

Get a Bark push on your iPhone when Agentstrap detects that you joined a Roblox server.

Agentstrap can send a push notification with the server's approximate location each time you join a game server. Notifications are delivered through Bark to the Bark app on your iPhone. This is separate from the in-game server connection overlay and the Windows tray hint.

Where it lives. Open Settings and select Server Connection Notifications. Activity tracking must be enabled.

Set it up

  1. Install Bark on your iPhone, open it, and copy your device push key.
  2. In Agentstrap, paste the key into Bark push key and press Save credentials.
  3. Optionally enter an IPinfo token for more reliable city and region lookups. Without one, Agentstrap uses IPinfo's public quota.
  4. Turn on Send server connection notifications and press Save in Settings.
  5. Use Test notification to check Bark delivery. Use Test IPinfo connection to check the optional location token.

Allow notifications for Bark in iOS. A successful test means Bark accepted the push request; the final alert is delivered by Bark and iOS.

Options

OptionDefaultWhat it does
Send server connection notificationsOffEnables Bark pushes when a Roblox server join is detected.
Include the server's IP addressOffAdds the remote game server IP to the notification body.
Duplicate suppression window30 minutesSuppresses another push for the same server during this interval. Set it to 0 to disable suppression.
Detailed diagnostic loggingOffAllows full remote server IP addresses in Agentstrap logs to help troubleshoot notifications.

Location and notification contents

When enabled, Agentstrap sends the game server's public IP address to ipinfo.io for a location lookup. The lookup uses the game server's IP, not your own IP. If the lookup fails, the Bark push still goes out without location details. If Include the server's IP address is on, that server IP is also included in the push text.

Agentstrap sends the notification title and body and your Bark device key to Bark's API over HTTPS. The device key and optional IPinfo token are stored encrypted for your Windows account with DPAPI; they aren't written to Settings.json or included in Agentstrap logs. The notification uses the Agentstrap PNG as its Bark icon. Bark's custom icon is supported on iOS 15 and later.

When nothing arrives

  • Make sure activity tracking and Send server connection notifications are both on.
  • Check that the saved Bark key is current and that Bark is allowed to show notifications on your iPhone.
  • Try Test notification. The status below the button reports whether Bark accepted the request.
  • If notifications arrive without a city or region, test the IPinfo token and check whether its plan includes location fields.
