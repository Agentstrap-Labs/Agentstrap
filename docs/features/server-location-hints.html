Server location hints

Work out roughly where a Roblox server's data centre is, and get the details on demand.

When you join a server, Agentstrap can work out approximately where that server is hosted. The provider is ipinfo.io, and the result is cached for the duration of the session.

Where it lives. Settings → Integrations → Query server location. Off by default. Requires activity tracking.

How you see it

The tray notification

When you connect, Windows shows a balloon notification:

Connected to public server
Location: Chicago, Illinois, US
Click for more information

The title reflects the server type — Connected to public server, Connected to private server or Connected to reserved server. The notification stays for ten seconds, and clicking it opens the Server information dialog.

The Server information dialog

Open it from the Agentstrap tray icon's right-click menu while you're in a game.

FieldShows
TypePublic server, private server or reserved server.
Instance IDThe Roblox job ID for the server you're in.
Location Only shown when server location querying is enabled. It starts at "Loading, please wait..." and becomes City, Region, Country, or "Not available" if the lookup failed.

There's a Copy Instance ID button for when you need to share the server with someone. The dialog closes itself when you leave the server.

Why the location can be "Not available"

  • The server's address isn't publicly queryable — private servers in particular are never looked up.
  • ipinfo.io was unreachable or rate-limited. Agentstrap's free-tier limit is easy to hit if you join games very quickly; the error message says "The server location could not be queried. You may be joining games too quickly."
  • ipinfo.io didn't have a more precise answer than the region itself. Agentstrap would rather show nothing than claim "Illinois, Illinois".
Failed lookups are cached too. Once a server's address fails to resolve, Agentstrap remembers that and doesn't keep retrying it.

Accuracy

The location describes the server's data centre, not your physical position. Roblox servers run in Google Cloud regions, so the city name tells you roughly which continent and region the game is running in. For serverhopping purposes — finding a low-ping server — it's genuinely useful. For "where am I", it isn't.
