Custom integrations

Launch other programs automatically when Roblox starts, and close them when it stops.

Custom integrations let you hook other programs onto Roblox launches. A common use is running a companion app, a voice tool or a chat client alongside the game, without having to start it yourself every time.

Where it lives. Settings → Integrations → Custom Integrations.

Fields

FieldMeaning
Name A label for the entry, shown in the list. New entries start as "New Integration".
Application Location The full path to the program to launch, for example C:\Windows\System32\cmd.exe. There's a Browse button next to it so you don't have to type paths.
Launch Arguments Any command line arguments to pass. The placeholder is "Roblox is running!". Arguments can span multiple lines.
Auto close when Roblox closes When checked, Agentstrap closes the launched process when Roblox exits. Leave it off for programs that are meant to keep running.

Adding and removing

  • New adds an entry named "New Integration" and selects it for editing.
  • Delete removes the selected entry. It's disabled when nothing is selected.
  • Select an entry in the list to edit its fields. The list shows the name of each integration.
Integrations launch alongside Roblox. They start when Agentstrap launches Roblox, not when you open the settings window.
