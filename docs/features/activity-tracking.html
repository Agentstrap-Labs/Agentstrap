Agentstrap Docs

Activity tracking

The master switch that lets Agentstrap see what you're playing — and everything built on top of it.

Activity tracking is how Agentstrap works out which game you're in and which server you joined. Several other features are built on it, and it has to be on for any of them to work.

Where it lives. Settings → Integrations → Activity tracking. On by default.

What it enables

FeatureNeeds activity tracking?
Server location hintsYes
Server connection overlayYes
Game historyYes
Discord Rich PresenceYes
Don't exit to desktop appYes
Turning it off turns other things off too. Disabling activity tracking immediately switches off server location, the connection overlay, the desktop-app patch and Discord Rich Presence, and greys out their rows.
They don't come back automatically. Turn activity tracking back on and the other switches are still off. You have to re-enable each one by hand. This catches people out regularly, so check the Integrations page after switching tracking back on.

How it works

Agentstrap starts a background watcher process while Roblox is running. The watcher tails Roblox's own log file and reacts to specific entries, such as:

[FLog::Output] ! Joining game
[FLog::Network] UDMUX Address = ...
[FLog::Network] Replicator created: ...
[FLog::SingleSurfaceApp] leaveUGCGameInternal

From those it works out the game you're in, the server address, the server type and the session timings.

This is the fragile part of Agentstrap. The log entries Agentstrap depends on are not a supported interface — the code itself calls them "technically volatile". Roblox can change its logging behaviour at any time, and if it does, activity tracking stops working silently. If features that depend on it suddenly do nothing, check the Agentstrap log first.

Privacy

Activity tracking is local: Agentstrap reads Roblox's log file on your machine. It does not report what you're playing to anyone, with one exception — if you enable Show Roblox account in Discord Rich Presence, your Roblox user ID and avatar are fetched from Roblox's public API so they can be displayed on your Discord profile.

Roblox's own API calls that Agentstrap makes are read-only lookups of public metadata.
