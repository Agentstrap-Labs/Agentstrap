Don't exit to desktop app

Make Roblox fully close when you leave a game, instead of dropping back to the desktop app.

By default, leaving a Roblox game returns you to the Roblox desktop app rather than closing the client completely. Turning this on makes the client fully exit.

Where it lives. Settings → Integrations → Don't exit to desktop app. Off by default. Requires activity tracking.

What it affects

With the option enabled, quitting a game closes the Roblox client instead of showing the app chooser. The next launch therefore starts from a completely clean client.

It also disables the Game history item in the tray menu, because the history is tied to a running session.

This will break some things. The setting is labelled with a warning in the interface for a reason. Features that rely on the Roblox app surviving — including Agentstrap's own game history — stop working.
