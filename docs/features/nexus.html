NEXUS mode

An opt-in experimental feature channel for people who want changes before everyone else gets them.

NEXUS is Agentstrap's optional feature channel. It's a way for experimental behaviour to be enabled without shipping it to everyone, and it's off unless you explicitly turn it on.

Where it lives. Settings → Advanced → NEXUS.

Options

OptionDefaultWhat it does
Enable NEXUS mode Off Pulls feature flags and configuration from the NEXUS channel instead of the defaults. Turning it on shows a warning first, because it can change how Agentstrap behaves during a launch.
Channel stable Which NEXUS channel to track. stable is the tested one, preview gets changes first, and nightly is the most experimental.
Verbose logging Off Writes an extra NEXUS log entry for every flag it resolves, which makes flag problems much easier to trace.
Allow mod overrides Off Lets a mod replace NEXUS-provided configuration. Useful when testing, but it can conflict with NEXUS itself.

A status card under the options shows whether NEXUS is enabled and which channel it's on, with a Refresh button to re-read the state.

Resetting

Reset to defaults turns NEXUS off, puts the channel back to stable, and switches off both verbose logging and mod overrides. It saves immediately and asks for confirmation first, because it clears settings outright.

Current status

NEXUS is a local opt-in in this build. The channel selection, verbose logging and mod override settings are stored and reported, but Agentstrap doesn't currently fetch anything from a NEXUS channel — there's no network request behind it yet. Enabling it today mainly acts as a flag for the feature set, and it's what unlocks the developer tools described below.

Because it's experimental and unfinished, treat NEXUS as a preview of what's coming rather than a feature to depend on. If something behaves oddly with NEXUS on, that's likely why.

Developer tools

The Advanced page also has a set of developer tools. They're hidden behind a lock, and unlock when either developer mode or NEXUS mode is enabled.

ToolWhat it does
Dump runtime environmentWrites OS, runtime and install details to the log.
Open log directoryOpens the folder containing Agentstrap's logs.
Clear logsDeletes every log file Agentstrap has written.
Copy environment summaryCopies the version, Windows build and install paths to the clipboard.
Restart AgentstrapRelaunches Agentstrap with the current settings.
Clear logs deletes everything. It removes every file in the log folder, including the one currently being written to, and it can't be undone. It asks for confirmation first.

The same Clear logs and Open logs buttons are always visible on the page, even while the tool list itself is locked.

Maintenance

Under Maintenance you'll also find Dump configuration, which writes a snapshot of your environment to the log file, and Restart Agentstrap, which saves your settings and relaunches the app.
