Agentstrap Docs

Updates

Check Agentstrap, your installed mods, and your configuration independently.

The Updates page has four separate sections. Each one is checked on its own, so you can check just the thing you care about instead of waiting for everything.

Where it lives. Settings → Updates. Check everything runs all four sections at once, and opening the page runs it automatically.

Agentstrap

Shows your installed version next to the latest published version, and a status line.

  • Check queries the GitHub releases API for the newest published release.
  • Releases opens the releases page in your browser.
Agentstrap doesn't update itself. There's no download-and-install button. The Releases link opens GitHub in your browser and you take it from there. The "Check for updates" setting controls whether Agentstrap queries GitHub at all.

Mods

Agentstrap can check whether your installed mods are out of date, using the manifest in %LOCALAPPDATA%\Agentstrap\Modifications\Mods\manifest.json.

  • Check scans the manifest and reports anything outdated.
  • Mods folder opens the Modifications folder.

Each mod entry can carry a releaseApiUrl. Agentstrap fetches that URL and looks for tag_name, version or latest_version in the response, then compares it with the version recorded on disk. Mods without a releaseApiUrl are skipped, so the check never reports a false positive.

It reports, it doesn't install. The Mods section tells you which mods are outdated. It never downloads or applies an update for you.

Configuration

Agentstrap keeps a schema revision for your configuration. When a future version changes the shape of Settings.json, a migration cleans up the old data.

  • Check validates the stored configuration against the current schema revision and reports what's pending. It never writes anything.
  • Apply runs the pending migrations and saves your settings, state and Fast Flags.

There are two migrations defined so far:

MigrationWhen it appliesWhat it does
Drop matchmaker place ID The matchmaker is enabled but no place ID is set. Turns the matchmaker off, rather than leaving it enabled with nothing to join.
Normalise process priority The stored process priority isn't a value Windows accepts. Resets it to Normal.
Check before you apply. Because Check is read-only, you can see exactly what a migration would do before you commit to it.

NEXUS

Reports the local state of the experimental feature channel — whether it's on and which channel it's tracking. It's a local check with no network traffic. See NEXUS mode.

Update checking

Whether Agentstrap queries GitHub at all is controlled by Check for updates on the Quality of Life page, and it's on by default. When it's off, the Agentstrap section reports "Update checking is disabled" instead of querying.
