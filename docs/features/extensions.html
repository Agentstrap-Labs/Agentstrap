Agentstrap Docs

Extensions

Optional Agentstrap extensions with a versioned manifest and least-privilege permissions.

Extensions are optional add-ons. They are validated before installation and never run with administrator privileges by default.

Manifest

Every extension ships a manifest.json with a unique id, display name, version, author, minimum compatible Agentstrap version, supported operating systems, declared permissions, entry type and optional dependencies. Malformed manifests are rejected.

Security

  • Path traversal in archive entries is blocked.
  • Package integrity is verified where possible.
  • Sensitive permissions require explicit consent.
  • Authentication tokens and private configuration are not exposed.
