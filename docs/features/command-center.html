Agentstrap Docs

Command Center

The default settings page: launch Roblox, see what's going on, and jump to the tool you need.

The Command Center is the first item in the settings sidebar and the page Agentstrap opens on. It exists to answer three questions quickly: can I launch right now?, is everything healthy? and where do I go next?

Where it lives. Settings → Command Center. It is the default landing page.

Launch

ButtonWhat it does
Launch Roblox Starts the Roblox Player through Agentstrap, showing the normal bootstrapper progress window. It re-registers the roblox:// and roblox-player:// protocol handlers, records the launch status, and may prompt for administrator rights.
Launch Roblox Studio The same, for Roblox Studio. Studio launches skip the "confirm launches" prompt.
Media Feature Pack. Launching Roblox needs the Windows Media Feature Pack. If mfplat.dll is missing, the launch fails with "Launch failed — Windows Media Feature Pack (mfplat.dll) is missing." Install Media Feature Pack for Windows from Windows Optional Features and try again.

Status

Six read-only cards. They tell you the state of the install at a glance.

CardShows
Roblox Player Installed or Not detected, based on whether the player executable exists inside the current version folder. If it isn't installed yet, it gets installed the next time you launch.
Last launch The outcome of the most recent launch — for example Roblox process started, Client startup detected, Launch cancelled, Launch failed or Launch did not complete — with the local time it happened. Defaults to No launch recorded.
AgentstrapThe running build version.
NEXUS Off, or On (channel) when the experimental feature channel is enabled. See NEXUS mode.
Process priority The priority applied to the Roblox process — Realtime, High, Above normal, Normal or Below normal. Defaults to Normal.
Test mode Whether test mode is on. Test mode is toggled from the status bar of the settings window, not from this page. It makes Agentstrap relaunch Roblox after settings close, and reopen settings after Roblox closes, in a loop.

Tools

ButtonWhat it does
Check for updatesJumps to the Updates page.
Run diagnosticsJumps to the Diagnostics page.
Open logsOpens Agentstrap's log folder in Explorer.
AdvancedJumps to the Advanced page.
Refresh status Re-checks whether the Roblox Player is installed. It deliberately only refreshes that one card — the launch, version, NEXUS, priority and test mode cards don't change.
Repair Roblox links Re-registers the roblox:// and roblox-player:// protocol handlers in HKCU\Software\Classes so they point at Agentstrap with -player "%1". Useful if clicking a Roblox link opens the wrong thing. No administrator rights needed.
Some of these are shortcuts, not actions. Check for updates, Run diagnostics and Advanced only navigate to another page — they don't start a check. Use Refresh status if you want the install card re-evaluated without leaving the page.
