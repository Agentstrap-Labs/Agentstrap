Deployment channels

Pin Agentstrap to a specific Roblox release channel instead of always following production.

Roblox ships several release channels. By default Agentstrap follows whatever channel Roblox itself would use. Setting a deployment channel pins Agentstrap to one specific channel, which is how you test against a pre-release build or deliberately stay on an older one.

Where it lives. Settings → Deployment → Roblox channel.

Options

OptionDefaultDetail
Deployment channel Empty The channel name to pin to. Leave it empty to follow Roblox's own channel selection. Channel names may contain letters, digits, hyphens and underscores, up to 64 characters.

There's no fixed list of channels in the interface — you type the name you want. The only channel Agentstrap knows about by name is production, which is what it falls back to when the field is empty.

Buttons

ButtonWhat it does
Check Resolves the channel against Roblox's client settings service and tells you the build it points at. With an empty field it checks production. A successful check reports the Roblox build version and GUID.
Apply channel Validates the name and saves it. This one saves immediately — you don't need to press Save afterwards.
Clear Empties the field and applies the empty value, so Agentstrap goes back to following Roblox's own selection.

An invalid channel name shows "Channel names can contain only letters, digits, hyphens, and underscores (up to 64 characters)." A channel that Roblox doesn't recognise reports "Could not resolve channel '{channel}'".

Which channel wins

Several things can request a channel. This is the order they take effect:

  1. The --channel command line argument.
  2. A channel: parameter inside a launch URI.
  3. Your saved deployment channel setting.
  4. The registry value HKCU\SOFTWARE\ROBLOX Corporation\Environments\RobloxPlayer\Channel\www.roblox.com.
  5. production.
Explicit launch links still take precedence. If you launch with a roblox:// link that names a channel, that wins over your saved preference. That's deliberate — a link should do what it says.

Agentstrap writes the resolved channel back to the registry value so that Roblox's own tooling agrees with it.

What actually changes on disk

Applying a channel only writes one key to Settings.json. The Roblox package itself is then downloaded from that channel's setup mirror and extracted into the usual version folder, exactly as a normal update would.

Stick to channels you know exist. Pre-release channels can contain builds that are unstable or mid-development. If a channel starts misbehaving, clear the setting and follow production again.
