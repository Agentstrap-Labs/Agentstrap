What is Agentstrap?

Agentstrap is a third-party replacement for the standard Roblox bootstrapper. It runs the game through its own launcher, which means it can add features Roblox does not offer — a matchmaker, an in-game server overlay, mod support, a diagnostics suite — while staying completely separate from the game client itself.

Agentstrap is a fork of Bloxstrap. Everything Bloxstrap does, Agentstrap does, plus a substantial set of new features that you can read about in the Features section.

Agentstrap is not a cheat tool. It does not patch the Roblox client to gain an unfair advantage, and it does not interact with the client the way exploits do. It changes how Roblox is launched and what is copied into the install folder. See Agentstrap and bans for the details.

Requirements

Operating system
Windows 10 or newer (64-bit)
Runtime
Bundled — the published build is self-contained, so no separate .NET install is needed
Privileges
Administrator access is requested when Roblox has to be installed or updated
Internet
Required to download Roblox, check for updates and look up server locations

Getting started

  1. Download and run Agentstrap. The first launch opens the installer, which places Agentstrap in %LOCALAPPDATA%\Agentstrap by default — you can pick a different folder — and registers the roblox:// protocol handler.
  2. Open the Command Center. Agentstrap's default settings page has one-click buttons for launching Roblox and Roblox Studio, a live status panel and shortcuts to the other tools.
  3. Turn on what you want. Most features are off by default. The Integrations page is the master switch for anything that watches what you're playing.
  4. Press Save. Changes on every settings page are held until you press Save in the bottom-right of the settings window. The snackbar confirms it, and reminds you that changes apply on the next Roblox launch.
Nothing is applied until you save. Every page writes into an in-memory copy of your configuration. If you close the settings window without saving, the changes are discarded — you'll be prompted first.

Getting help

If something here doesn't answer your question, the fastest route is the help section — it covers the failures people report most often. For anything else, open an issue on the issue tracker.

When you report a problem, running Diagnostics and attaching the report makes it far easier to help you. See Diagnostics for how to copy it.
